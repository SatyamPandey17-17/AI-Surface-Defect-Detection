# Combined Surface Defect Detection + Live Object Height

Files:
- `app.py` – light entry file (Live Object Height page + navigation)
- `ai_page.py` – your original AI defect-detection code (see step 1)
- `serial_uploader.py` – runs on the laptop, sends Arduino readings to Supabase
- `arduino_height_sensor.ino` – Arduino sketch
- `requirements.txt` – Streamlit Cloud dependencies

## 1. Create ai_page.py from your original code

1. Copy your original single-page Streamlit file and name the copy `ai_page.py`.
2. Delete the `st.set_page_config(...)` call (it is already in `app.py`).
3. Optionally delete the original `st.title(...)` / `st.caption(...)` lines.

## 2. Supabase table (SQL Editor)

```sql
create table public.height_readings (
  id bigint generated by default as identity primary key,
  object_height double precision not null,
  created_at timestamptz not null default now()
);

alter table public.height_readings enable row level security;

create policy "anon can read height readings"
on public.height_readings
for select
to anon
using (true);
```

## 3. Streamlit Cloud secrets (App -> Settings -> Secrets)

```toml
SUPABASE_URL = "https://YOUR_PROJECT_ID.supabase.co"
SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_PUBLIC_KEY"
```

## 4. Laptop uploader (Windows)

Close Arduino Serial Monitor first, then in Command Prompt:

```bat
python -m pip install pyserial requests
set SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
set SUPABASE_SERVICE_ROLE_KEY=YOUR_SUPABASE_SERVICE_ROLE_KEY
set ARDUINO_PORT=COM3
python serial_uploader.py
```

Never put the service-role key on GitHub or in Streamlit Secrets.

## 5. Deploy

Upload all files to your GitHub repo, set the main file to `app.py` in Streamlit Cloud, then reboot the app.
